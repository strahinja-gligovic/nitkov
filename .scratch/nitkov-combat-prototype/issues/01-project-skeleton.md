# 01 — Project skeleton

Status: done
Spec: ../spec.md

## What
- Godot project with an InputMap registered in code (keyboard/mouse and controller).
- Greybox arena built from a layout script: floor, walls, pillars, a ledge with a ramp, orb and spawn markers.
- Toon shader, ink-outline post-process, and a WorldEnvironment with a dark, colorful palette.
- Over-the-shoulder camera rig (spring arm, mouse and stick look), plus a player fighter that walks and sprints relative to the camera.

## Acceptance
- The game launches into the arena, you can walk and sprint around it, and the camera doesn't clip through walls.
- Screenshot shows banded toon lighting and ink outlines.
